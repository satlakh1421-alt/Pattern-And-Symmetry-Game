# 🔷 Pattern & Symmetry Game
An interactive educational puzzle game designed to sharpen spatial reasoning, geometric intuition, and pattern-recognition skills through symmetry challenges and sequence completion.

## 🚀 Features
- **Symmetry Puzzles:** Mirror patterns across horizontal, vertical, and diagonal reflection lines to complete shapes.
- **Pattern Recognition:** Identify sequences, repeating motifs, and missing elements in geometric grids.
- **Adaptive Difficulty:** Exercises scale from simple color/tile reflection to complex multi-axis patterns.
- **Instant Visual Feedback:** Real-time validation highlights matching or mismatched tiles immediately.
- **Lightweight & Fast:** Pure front-end build with zero heavy dependencies for smooth in-browser play.

## 🎮 How to Play
1. Start a new game session.
2. Observe the target pattern or reflection axis shown on the grid.
3. Click or tap empty tiles to mirror the given shape or choose the next logical pattern item.
4. Submit your solution to earn points, build streaks, and unlock new puzzle sets!

## 🛠️ Getting Started & Installation
To run or test this project locally:

1. **Clone the repository:**
git clone [https://github.com/satlakh1421-alt/Pattern-And-Symmetry-Game.git](https://github.com/satlakh1421-alt/Pattern-And-Symmetry-Game.git)

2. **Navigate to the project directory:**
cd Pattern-And-Symmetry-Game

Run the game:
Open index.html directly in your browser, or start a lightweight local server:
python3 -m http.server 8000
